# 🇫🇷 法国深度13天自由行 · 交互式旅游地图

> 2026.9.25 — 10.6 · 巴黎 → 波尔多 → 图卢兹 → 蒙彼利埃 → 里昂 → 日内瓦

一个功能完整的交互式旅游行程地图，帮助规划和管理法国 13 天自驾行程。纯前端单页应用，无需后端服务。

## ✨ 功能特性

### 🗺️ 交互地图
- 基于 **Leaflet.js** + OpenStreetMap 的开源地图层
- 所有景点标记在地图上，按天编号，鼠标悬停显示中文名称
- 点间连线使用 **OSRM 开源驾车导航API**，获取真实道路路线（非直线）

### 📅 每日行程
- 左侧侧边栏按天切换，显示当天行程摘要和景点列表
- 每个景点显示：类型徽标（📍景点 / 🍽️餐饮 / 🎯体验 / 🚗行程）、时间、预约状态
- 跨城驾车行程用箭头 ↓ 显示，含行驶时间、距离和预计到达时间

### 🔍 景点详情面板
点击任意景点弹出详情面板，包含：
- **简介** — 景点概况
- **必看亮点** — 核心推荐内容
- **门票价格** — 清晰标注费用
- **预约信息** — 表格形式展示：预约方式、建议提前时间、官网预约入口、多渠道预约选项、交通方式、休息日

### 📊 汇总表
- 全部 37 个景点/活动的汇总表格
- 支持筛选（仅看需预约）和排序（按日期 / 按预约紧急程度）
- 列信息：天、时间、景点名、分类、价格、预约状态、提前多久、最早预约日期、闭馆冲突检测、预约链接
- 底部统计：门票总价合计（€ + ¥换算）

### 🚗 驾车路线优化
- 跨城路线使用真实导航路径（OSRM）
- 12 天每日路线 + 一键总览全部路线
- 蓝色路线 + 白色描边，清晰可见

## 🛠️ 技术实现

### 技术栈
| 技术 | 用途 |
|------|------|
| HTML5 + CSS3 | 页面结构与样式 |
| Vanilla JavaScript (ES6+) | 全部交互逻辑，零依赖 |
| Leaflet.js 1.9.4 | 交互式地图引擎 |
| OpenStreetMap | 地图瓦片数据源 |
| OSRM (project-osrm.org) | 驾车路线导航 API |
| localStorage | 路线数据缓存（加速二次访问） |

### 架构说明
- **单页应用**：所有代码在一个 `.html` 文件中
- **数据驱动**：37 个景点数据以 JSON 格式内嵌，按 12 天行程组织
- **无后端依赖**：纯前端，所有 API 调用为客户端直接请求
- **并行加载**：路线请求 4 条一批并行，大幅减少加载时间
- **缓存机制**：已获取的路线数据缓存到 localStorage，二次打开秒加载

### 数据来源
- 行程规划来源：深度定制 Excel 攻略
- 景点坐标：手动标注（基于 Google Maps 坐标）
- 驾车路线：OSRM 实时计算
- 门票/预约信息：各景点官方网站

## 🚀 本地使用

```bash
# 克隆仓库
git clone https://github.com/szsyqq/travel-map.git

# 直接用浏览器打开
open travel-map/france-itinerary/index.html

# 或启动本地服务器（推荐，避免 CORS 问题）
cd travel-map/france-itinerary
python3 -m http.server 8000
# 访问 http://localhost:8000
```
